Launch Sequence

  1. Base rotates to the target direction.
  2. Motor tensions the wire.
  3. Release motor opens the stopper to throw.
  4. Tension motor relaxes.
  5. Motor untensions to reset the stopper.

Only wire tension is adjustable; launch strength is derived from tension.

Manual Servo Control

Servo Map

  • Release Servo: triggers launch release.
  • Tension Servo: adjusts the catapult draw.
  • Base Turn Servo: rotates the base up to 180°.
